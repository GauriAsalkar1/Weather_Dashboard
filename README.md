## 📌 About The Project

The Weather Forecast Dashboard is a React.js based web application designed to display real-time weather information for different cities. The application provides users with weather details such as temperature, humidity, wind speed, and weather conditions through a clean and responsive interface.

This project uses external weather APIs to fetch live weather updates and present them in an interactive format.

---

## ✨ Key Features

* 🌍 Search weather details by city name
* 🌡️ Display current temperature and weather conditions
* 💨 Show humidity and wind speed information
* 📅 Multi-day weather forecast support
* 📱 Fully responsive design for mobile and desktop
* 📍 Location-based weather detection using geolocation
* 🎨 Dynamic weather icons and modern UI design

## 🚀 Project Functionality

The application allows users to search for weather updates of any city in real time. It fetches weather data from the API and dynamically updates the user interface with weather statistics and forecast details.

The responsive layout ensures smooth usability across different screen sizes and devices.
